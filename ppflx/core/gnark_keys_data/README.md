# Pinned Groth16 keys

The key manifest and verifying keys this library checks proofs against. They
are the trust anchor: a proof is rejected unless it was made under the
verifying key pinned here (`docs/ZKP.md`, section 7).

They are generated by the proof service, not by this library:

    gnark_service setup --keys-dir <dir> --pk-dir <proving key cache>

and copied here. The proving keys are never distributed. Point
`FL_ZKP_KEYS_DIR` at another directory to check proofs under different keys.
